Sitio corporativo responsivo para **Nexo Digital**, una empresa ficticia de servicios tecnológicos. Integra HTML5 semántico, CSS3, Bootstrap 5.3.8, validación HTML5, usabilidad, accesibilidad y adaptación para computadora, tableta y teléfono.

## Uso del framework

El código identifica con comentarios los elementos de **Bootstrap**:

- navbar responsiva y colapsable;
- grid mediante `container`, `row`, `col-*`;
- cards de servicios;
- botones;
- controles y distribución del formulario.

`css/style.css` personaliza la identidad visual, Flexbox, estados `hover`/foco y media queries.

## Cómo abrir

Abre `index.html` en un navegador con conexión a internet para cargar Bootstrap desde CDN. No requiere instalación ni compilación. El formulario demuestra validación en el navegador y no transmite información real.
